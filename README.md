# SK5

一个只做 SOCKS5 转发的 Android 应用。没有浏览器、没有订阅系统、没有账号，
打开、填节点、点连接，整台手机的流量就走你的节点。

界面全中文，深色模式跟随系统。目标是把「连上一个 SOCKS5 节点」这件事做到最少步骤。

---

## 它解决什么

手机上用 SOCKS5 节点通常有两种办法，都不太顺手：

- 装一个功能齐全的代理客户端，但里面一堆用不到的协议、规则、订阅格式，
  配置项多到看不清自己在改什么。
- 用系统自带的代理设置，但只在 WiFi 下有效，切到移动网络就失效，
  而且部分 App 根本不读系统代理。

SK5 只做一件事：用一个开关，把系统流量接到你的 SOCKS5 节点上，管你是 WiFi
还是移动网络，管你是浏览器还是别的 App。

## 主要特性

| 特性 | 说明 |
|---|---|
| 一键连接 | 系统级 VPN 接管，所有 App 自动生效，不需要改服务器配置 |
| SOCKS5 节点 | 填地址、端口、账号密码；或直接粘贴 `socks5://user:pass@host:port` |
| 智能分流 | 国内域名直连，其余走节点，看国内站点不额外绕路 |
| 全局代理 | 全部流量经节点，一个开关切换 |
| 延迟测试 | 直接和节点握手测延迟，不经过隧道，避免误判 |
| 网络自检 | 分三级：节点握手 / 经节点访问 DNS / 经隧道访问 GitHub，直接指出哪一环不通 |
| 域名解析可选 | 自动 / 经节点 DoH / 本机解析；自动模式会先测节点能不能到 1.1.1.1 |
| 运行日志 | 出问题在应用内直接看，可一键复制，不用连电脑抓日志 |
| 崩溃可诊断 | 异常会连同最近日志保存，下次打开直接弹窗，可复制 |
| 中文提示 | 节点填错、链接格式不对、VPN 未授权、内核启动失败，都有明确中文说明 |
| 开机自连 | 可选，仅在已授权 VPN 时执行，不会开机弹授权框 |

## 使用

1. 打开应用，切到「节点」页。
2. 点「添加节点」，填服务器地址与端口；需要认证的填用户名和密码。
   也可以点「粘贴 socks5:// 链接导入」，一粘贴就自动拆好字段。
3. 回到「连接」页，点中间的大圆钮。
4. 首次会请求 VPN 授权，同意后开始连接，圆钮变绿即已接管系统流量。
5. 打开 GitHub、GitLab 等站点确认是否生效。

连上后等两三秒，到「设置 → 网络自检」可以看到三级检测结果。
设置页还可以切换分流模式、域名解析方式，以及打开「开机自动连接」。

## 系统要求

- Android 8.0（API 26）及以上
- arm64 设备
- 需要一个自己的 SOCKS5 节点

系统同一时间只能运行一个 VPN。如果装了其他代理类应用，需要先关掉它，
否则会互相抢占，表现为「看起来连上了但没网」。

## 智能分流是怎么判定的

按域名后缀匹配内置的国内常用域名列表（`.cn`、`.baidu.com`、`.qq.com`、
`.bilibili.com` 等），命中就直连，不命中走节点。

特意没有用「国内 IP 段」来判断：那需要先把域名解析成 IP 才能匹配，
等于每个国外域名都要多一次本地查询，既慢，也把你的访问目标交给了本地解析器。
域名后缀规则可以做到不查 IP 就分流。

## 常见问题

**连上了但网页打不开**

先看「设置 → 网络自检」，它分三级告诉你哪一环不通：

| 结果 | 含义与处理 |
|---|---|
| 节点失败 | 地址、端口或账号密码不对，或节点已失效 |
| 节点通过、DNS 失败 | 节点到不了境外 DoH，把域名解析改成「本机解析」或「自动」 |
| 前三项都通过但站点仍打不开 | 站点被阻断且节点在境内，需要换境外节点 |

**访问境外被屏蔽的站点无效**

这是最常见的一种。应用只负责转发，**节点在哪里，出口就在哪里**。
用国内节点时，被阻断的站点依然打不开；这不是客户端能绕过的事。
判断方法：智能自检里节点与隧道都通过，但目标站点仍然无法访问。

**提示「未获得 VPN 授权」**

在系统设置里找到「VPN」相关项，确认本应用有权限。部分手机会在后台清理时
撤销授权，重新点连接会再次弹出授权框。

**连接后应用自己退出了**

重新打开应用，会弹出上次的崩溃记录，点「复制」即可取得详细信息。
如果没弹窗，进「设置 → 运行日志 → 复制」，最后一行就是退出前到达的步骤。
日志中的用户名与密码已经脱敏，可以安全贴出来。

**连接很快但速度慢**

速度取决于节点本身的带宽与线路质量，应用只做转发，不做加速。
可以试试节点页的「测试延迟」，延迟低但速度慢通常是节点带宽或线路问题。

**手机上还有别的 VPN 应用**

同时只能有一个 VPN 生效。两个都开着时，后启动的那个不一定能接管成功，
建议只保留一个。

## 说明

本项目只负责把你自己的流量转发到你自己的节点，**不提供节点、不内置任何服务器地址、
不做订阅分发**。请自行准备合法的 SOCKS5 服务。
